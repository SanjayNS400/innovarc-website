# InnovArc website

A responsive, static website for InnovArc. It uses only HTML, CSS and vanilla JavaScript; there is no build step or package installation.

## Preview locally

Open `index.html` in a browser, or run a local static server from this directory, for example:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish

Upload the complete `innovarc-site` folder to a static host such as Netlify, Cloudflare Pages or GitHub Pages. No server-side environment is required. The inquiry form uses the visitor's email application to prepare a message for `info@innovarcdesigns.com`; it does not store or transmit form data itself.

## Before launch

- Confirm the public contact email is `info@innovarcdesigns.com`.
- Replace or approve the portfolio images and project descriptions for public use.
- Add verified client names, project facts and testimonials only after approval.
- Connect a domain and configure the host's HTTPS setting.
